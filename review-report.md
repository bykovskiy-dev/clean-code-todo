# Отчёт ревью

Код приложения не менялся. Замечания ниже — только разбор.

## Мёртвый код

Не найдено. Пустой обработчик `ajaxRequest` удалён, неиспользуемых функций и переменных нет.

## Дублирование

### Разметка задачи описана дважды

1. Место: готовые задачи в `index.html` (элементы `li` в `#incompleteTasks` и `#completed-tasks`) и сборка новой задачи в `createNewTaskElement` в `app.js`.
2. Проблема: строка задачи — одно и то же знание: чекбокс, подпись, поле редактирования, кнопки Edit и Delete с `remove.svg`. Оно записано и в HTML, и в JavaScript.
3. Условие: при добавлении нового обязательного элемента или класса его легко вписать только в одно из мест. Старые задачи и только что добавленные начинают вести себя по-разному.
4. Проверка: добавить задаче обязательный `data-атрибут` только в `createNewTaskElement`. Новая задача получает атрибут, «Pay Bills» — нет.

## Имена

### Класс шапки не говорит, что это

1. Место: `index.html`, блок `div.aaa` и ссылка `a.more_inf`; те же классы в `style.css`.
2. Проблема: `aaa` не означает ничего. `more_inf` сокращает текст ссылки и записан иначе, чем остальные классы (`task-row-wrapper`). По имени не понять, что это шапка с картинкой матрицы и ссылкой на пояснение.
3. Условие: при правке шапки класс приходится искать по файлам, а не по смыслу.
4. Проверка: переименовать классы в HTML и CSS в пару вроде `page-header` и `details-link`. Картинка, ссылка и выравнивание остаются теми же.

### Кнопка Add находится как первая кнопка документа

1. Место: `app.js`, `document.getElementsByTagName("button")[0]`.
2. Проблема: имя `addButton` верное, но способ поиска — нет. Комментарий рядом нужен именно потому, что строка сама не говорит, почему взята первая кнопка.
3. Условие: любая новая кнопка выше кнопки Add в разметке забирает обработчик. Щелчок по Add перестаёт создавать задачу.
4. Проверка: поставить кнопку перед Add, нажать Add — задача не появляется. После замены поиска на `getElementById` с отдельным `id` у кнопки Add задача снова добавляется, а новая кнопка ничего не перехватывает.

## Комментарии

Не найдено отдельных проблем. Оставшиеся два комментария объясняют причину: у кнопки Add нет `id`, а `innerText` не превращает символы задачи в разметку.

## Функции

### editTask делает два разных действия

1. Место: `app.js`, функция `editTask`.
2. Проблема: один щелчок то начинает редактирование, то сохраняет текст. Ветки `if` и `else` — разные операции.
3. Условие: правка только сохранения, например запрет пустого текста, оказывается в той же функции, что и вход в режим редактирования. Легко задеть вторую ветку.
4. Проверка: вынести сохранение и вход в редактирование в две функции с собственными именами. Edit по-прежнему переключает текст кнопки между Edit и Save, пустая новая задача по-прежнему не добавляется.
